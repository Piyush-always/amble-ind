THE AMBLE PLAY LAB

One setup.
So many ways to play.

Amble Beats is not one fixed game. The same interactive characters can become music challenges, memory games, movement activities, team games and open-ended creative play.

Frequently asked

Questions schools may have.

What is Amble Beats?

Amble Beats is an interactive musical installation designed for schools and educational spaces, turning physical interaction into musical responses.

How many characters are included?

The current configurations shown on this website use eight characters.

Can it be installed in different ways?

Yes. The website demonstrates an open-floor configuration and a raised drum-set style configuration.

Can the installation be customised?

Customisation can be discussed based on the space, configuration and institutional requirements.
